# UI 設計原則：禁止無意義裝飾性文字與偽遙測

在為 CareerDNA 或本專案進行任何頁面設計或程式碼修改時，必須嚴格遵守以下準則：

1. **嚴禁添加偽系統代碼與虛擬遙測字串**：
   - 嚴禁出現 `SYS // ...`, `LATENCY: <XXms`, `STATUS: ONLINE`, `GATEWAY: ...`, `v2026`, `CORE_ENGINE` 等偽終端機/假黑客代碼。
   - 所有系統狀態必須對應真實功能，若無實際遙測數據，不得以裝飾性文字填充。

2. **去除無意義的序列號與微型標籤**：
   - 避免在標題或卡片上方堆疊無意義的 `01 / 02 / 03` 數字或純英文小標（例如在「AI 履歷健檢」上方放 `ATS AUDIT`）。
   - 保留清晰、自信的單一標題與簡潔說明，不使用裝飾性副標徽章分散使用者注意力。

3. **貫徹 Impeccable 極簡與高質感排版**：
   - 主色使用克萊茵藍（#002FA7）與晶透冰藍（#EBF2FF / #C7DCFF），搭配純白（#FFFFFF）卡片背景。
   - 留白與層級由字級大小、字重（Syne Black / Noto Sans TC）、空間呼吸感決定，而非依靠繁複的邊框微字。
   - 所有文案必須說人話、自然流暢且具備台灣繁體中文專業語感。
